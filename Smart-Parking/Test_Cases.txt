SMART PARKING SPACE ALLOCATION SYSTEM
Set 8 | Roll number group: 85–90

Run the program once. It asks for three vehicle requests in sequence.
The following test cases assume the initial data in SMARTPARK.PRO.

TEST CASE 1 – REGULAR CAR
Input:
    Vehicle type: car
    Requirement: regular

Expected result:
    Allocated Space: P9
    Space Type: compact
    Distance: 1
    Status: Successfully Allocated

Reason:
    P9 is the nearest candidate for a regular request and is compatible
    with a car. It is initially available.

TEST CASE 2 – ACCESSIBLE CAR
Input:
    Vehicle type: car
    Requirement: accessible

Expected result:
    Allocated Space: P6
    Space Type: accessible
    Distance: 2
    Status: Successfully Allocated

Reason:
    P6 is the nearest available accessible space.

TEST CASE 3 – LARGE SUV
Input:
    Vehicle type: suv
    Requirement: large

Expected result:
    Allocated Space: P8
    Space Type: large
    Distance: 4
    Status: Successfully Allocated

Reason:
    P8 is the nearest available large space.

IMPORTANT:
These three tests use separate categories, so the earlier allocations do not
remove candidates needed by the later tests. For an allocation-failure test,
occupy all spaces that are candidates for a chosen requirement before making
that request, or change their initial statuses in the database.
